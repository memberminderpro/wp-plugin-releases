# WordPress plugin releases

Public distribution feed for Member Minder Pro, LLC WordPress plugins. The
development repositories stay private; this repository holds only update
manifests and release zips, so sites can update themselves without a token.

```
plugins/<plugin>/<stable|beta>/latest.json
releases/download/<plugin>@<version>/<plugin>-<version>.zip
```

Each manifest names the plugin, its channel, the version, the download URL and
the SHA-256 of the zip. See `DISTRIBUTION.md` in any plugin repository for the
full model.
